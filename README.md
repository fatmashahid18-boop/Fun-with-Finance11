# Fun-with-Finance11
Finance game

An interactive, story-driven web toy game built for the frontend track (Option A) that tests supply chain logic, economic strategy, and demand-and-supply deduction across 3 progressively challenging levels.  
Description
In Fun with Finance, players manage initial capital, credit ratings, and compounding inflation while interacting with quirky characters. Instead of direct instructions, characters share their personal stories, requiring players to logically deduce who holds resources, who needs them, and how trade sequences flow.  
Key Features
Tech Stack: Built with pure HTML, CSS, and JavaScript.  
3 Progressive Levels: Ranging from a local village market to high-tech silicon hubs and global aerospace syndicates.
Cryptic Storytelling: NPC dialogue boxes with animated avatars and custom lore.
Economic Pressure: Real-time inflation scaling and credit tracking with emergency loan mechanics.
Audio Feedback: Web Audio API synthesized cash register sound effects on clicks and trades.
Vibrant UI: Custom color palette featuring rich pinks, purples, greens, yellows, and sky blues with smooth CSS animations.
